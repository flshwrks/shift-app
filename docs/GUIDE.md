## 1. 全体構成

このアプリは「同一組織の複数店舗＋本部管理」というモデルで動く。

| ロール | 所属 | できること |
|---|---|---|
| **本部管理者** | どの店舗にも属さない | 全店舗を横断管理。店舗の追加・編集・削除 |
| **店舗管理者** | 必ず1店舗 | 自店のシフト・スタッフ・設定・人件費・アンケート・調整依頼を管理 |
| **スタッフ** | 必ず1店舗（掛け持ち不可） | 自分のシフト申請・全員のシフト確認・調整依頼への応答 |

## 2. ログイン方法（3種類のURL）

| 用途 | URL | 認証 |
|---|---|---|
| 店舗のスタッフ・店舗管理者がログイン | `/s/[店舗ID]/login` | 名前選択 + PIN（4桁） |
| 本部管理者がログイン | `/admin/login` | 名前選択 + PIN（4桁） |
| **ログイン不要**でシフト表だけ閲覧 | `/s/[店舗ID]/public/schedule` | 不要（誰でも見られる） |

- 店舗ごとのログインURLは店頭にQRコードとして掲示する運用を想定している。URLは本部管理者が `/admin/stores` からいつでもコピーできる
- PINを5回連続で間違えると15分間ロックされる
- 旧URL（`/login`, `/staff/*`, `/admin/schedule` 等、多店舗対応前のもの）にアクセスすると自動的に新しいURLへ転送される

### ログイン不要のシフト閲覧について（`/public/schedule`）

店舗ログイン画面の「シフト表を見る（ログイン不要）」から開ける。休憩室のタブレット等に固定して、PIN入力なしでその日の予定を確認する用途を想定している。

- 表形式・タイムライン両方の表示に対応
- シフトをタップすると時間・ステータスの詳細が見られる（コメントは表示しない）
- **提出・編集・確定などの操作は一切できない、完全な読み取り専用**
- **注意**: このURLを知っていれば誰でも閲覧できる（PIN不要）。店舗のスタッフ名とシフト予定が、ログインなしで見える状態になることを踏まえて運用すること

## 3. スタッフ向け機能

### シフト申請（`/s/[店舗ID]/staff/shifts`）

1. ナビの「申請」を開く（提出期間が設定されている月は自動でその月に切り替わる）
2. 日付ごとに「入力」→ シフト種別（A〜G/カスタム）または「休み」を選んで決定
3. 画面下部の「まとめて提出」で確定申請（提出前はローカルに自動下書き保存される）

**便利機能**
- 前月コピー：先月と同じ曜日パターンをそのまま引き継ぐ
- 複数日コピー：入力済みの1日を選んで他の日へ一括適用
- 提出期間外はロックされ、入力・コピー・提出ボタンが非表示になる（詳細は[提出期間ロジック](#提出期間のロジック)を参照）
- 確定済み（管理者が承認済み）のシフトは編集不可。変更したい場合は調整依頼で対応する

### シフト確認（`/s/[店舗ID]/staff/schedule`）

全スタッフのシフトを閲覧できる（読み取り専用）。

- 表形式：日付×スタッフのグリッド。「実働時間」行で日ごとの合計稼働時間、「月計」列で個人の月間合計時間が分かる
- タイムライン：時間帯×日のガントチャート風表示。時間帯ごとの人数の疎密が一目でわかる
- 日付ごとのメモ（店舗管理者が入力）を閲覧できる
- Realtime同期：他のスタッフ・管理者の変更が即座に反映される

### 調整依頼への対応（`/s/[店舗ID]/staff/requests`）

店舗管理者からの「この日入れる人いませんか」を確認・応答する画面。

- **指名型**：特定のスタッフ宛て。「受ける」「断る」で応答
- **掲示板型**：全員に公開、早い者勝ち。誰かが先に受けると自動的に締め切られる
- 「受ける」と、その日のシフトが自動的に下書き登録される（既存シフトがある場合は上書き確認あり）
- ログイン時、未対応の依頼や承諾後に取り消された依頼があればポップアップで通知される

## 4. 店舗管理者向け機能

店舗管理者は上記のスタッフ向け機能に加えて、以下の管理画面を使える。

### シフト管理（`/s/[店舗ID]/admin/schedule`）

- スタッフの申請（未確定・黄色）を個別確定、または「すべて確定」で一括承認
- 「+シフト追加」で管理者が直接シフトを作成
- セルクリックで編集・削除
- 「未提出者」ボタンで未提出スタッフの一覧とリマインダー文言（LINE/メール貼り付け用）をコピー
- 日付ごとのメモを入力・保存（スタッフ側にも表示される）

### 調整依頼の作成（`/s/[店舗ID]/admin/requests`）

- 「+依頼を出す」で日時・指名型/掲示板型・メッセージを指定して送信
- タイムラインの人数不足のコマをタップすると日時が自動入力された状態で作成できる
- 「募集中」タブで各スタッフの応答状況（承諾/辞退/未対応）を確認
- 承諾されたら「承諾済み」タブから「シフトを確定する」で下書きシフトを確定

### スタッフ管理（`/s/[店舗ID]/admin/staff`）

- 「+スタッフを追加」：名前・PIN（4桁）・権限（スタッフ/管理者）を設定
- 編集：名前・権限・PINの変更
- 表示順の並び替え（▲▼、シフト表の列順に反映）
- PINの表示/非表示切り替え

### 設定（`/s/[店舗ID]/admin/settings`）

- **店舗名**：表示のみ（読み取り専用）。変更は本部管理者が `/admin/stores` から行う
- **シフト提出期間**：月ごとにスタッフが申請できる期間を開始日〜終了日で設定。未設定の月は原則いつでも申請可能（詳細は[提出期間ロジック](#提出期間のロジック)を参照）

### 人件費予測（`/s/[店舗ID]/admin/labor-cost`）

- 過去2ヶ月〜先4ヶ月のタブで月を切り替えて確認
- スタッフごとに時給を設定（デフォルト ¥1,268 = 神奈川県最低賃金 2024年10月時点。実際の時給に合わせて要調整）
- 月間実働時間 × 時給で概算人件費を自動計算し、スタッフ別・合計を表示
- あくまで概算（残業・深夜割増・各種手当・社会保険料等は含まない）

### アンケート管理（`/s/[店舗ID]/admin/survey`）

- タイトル・説明・選択肢（2つ以上、「その他（自由記述）」の追加も可）を設定して下書き作成
- 「公布する」で実施中に変更（実施中は同時に1件まで。新しく公布すると既存の実施中は自動的に終了する）
- 結果はリアルタイムで集計され、選択肢ごとの得票数・割合をグラフ表示。「その他」の自由記述も一覧で見られる
- スタッフはログイン後、未回答の実施中アンケートがあればポップアップで回答を促される

## 5. 本部管理者向け機能

本部管理者はどの店舗にも属さず、全店舗を横断的に扱える。

### 店舗管理（`/admin/stores`）

- 「+店舗を追加」：店舗名・店舗ID（slug、英小文字・数字・ハイフン、例: `umeda`）を指定して新しい店舗を作成
- 編集：店舗名・店舗IDを変更
- 削除：**スタッフが1人でも登録されている店舗は削除できない**（誤削除防止）
- 「ログインURLをコピー」：その店舗のログインURL（`/s/[店舗ID]/login`）をコピー。QRコード作成に使う
- 「この店舗を管理」：その店舗の管理画面（シフト管理・スタッフ管理等）へ遷移し、本部管理者としてそのまま操作できる

### 店舗の行き来

- 店舗の管理画面のヘッダーにある「本部管理へ戻る」リンクで、**ログアウトせずセッションを保ったまま** `/admin/stores` に戻れる
- 「ログアウト」ボタンはセッションを完全に破棄する（次回は`/admin/login`でPIN再入力が必要）。単に本部へ戻りたいだけなら「本部管理へ戻る」を使う

## 6. 共通ルール・仕様

### シフト種別

| 種別 | 時間帯 | 時間数 |
|---|---|---|
| A | 8:00〜13:00 | 5h |
| B | 9:00〜14:00 | 5h |
| C | 8:00〜17:00 | 9h |
| D | 9:00〜18:00 | 9h |
| E | 13:00〜22:00 | 9h |
| F | 17:00〜22:00 | 5h |
| G | 9:00〜22:00 | 13h |
| カスタム | 任意（08:00〜22:00の範囲） | 30分刻み |
| 休み | — | — |

### 実働時間の計算方法（休憩控除）

シフト管理・人件費予測などで表示される「実働時間」は、労働基準法の休憩ルールに沿って以下の通り自動控除している。

- 実働8時間超 → 60分控除
- 実働6時間超8時間以下 → 45分控除
- 実働6時間以下 → 控除なし

例: シフトC（8:00〜17:00、9時間）の実働時間は 9h − 60分 = **8時間**。

### 提出期間のロジック

```
periodSet   = 開始日 または 終了日が設定されている
inPeriod    = (開始日が空 または 今日 ≥ 開始日) かつ (終了日が空 または 今日 ≤ 終了日)
isFarFuture = 期間未設定 かつ 表示月が今日から3ヶ月以上先
isLocked    = isFarFuture または (periodSetかつ !inPeriod)
```

ロック中はシフト申請画面の入力ボタン・コピーボタン・提出フッターが非表示になり、赤いバナーで理由が表示される。

### PINと認証

- PINは4桁の数字。ハッシュ化（bcrypt）してDBに保存され、平文では保持されない
- 5回連続で間違えると15分間ロックアウトされる
- ログインセッションは30日間有効
