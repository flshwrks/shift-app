# KING OF TIME 連携を保留にした（コードは `wip/kot-csv-export` に退避）

## 対象

- コード変更なし（`master` から KING OF TIME 連携を外した記録）
- 実体はブランチ `wip/kot-csv-export`（コミット `458bd9c`）

## 変更内容

2026-08-23〜24 に実装した KING OF TIME 連携（確定シフト → スケジュールCSV出力）を、
`master` に入れずブランチへ退避した。`master` 側では次の状態になっている。

- この機能のコード・画面・ヘルプは一切入っていない（利用者から見える変更は無い）
- CHANGELOG の 2.10.0 エントリも入っていない。`master` の最新版は **2.9.2**
  （2026-08-25 のシフトコメント表示。KOT の 2.10.0 より先に出したためパッチ番号で切り直した）

## 理由

アプリ側の実装は完成し `npx tsc --noEmit` / `npm run build` / `npm run check:guide` /
`npx tsx scripts/kot-smoke.ts` も通っているが、**KOT側の準備が現状では難しく**、
実際の取り込み検証まで到達できないため。アプリ側では解決できない未確認事項が残っている。

- KOT側で「入力レイアウト」を新規作成できるか（管理者権限の範囲が不明）
- 自店スタッフ全員分の従業員コード（`000` と `1592` のように桁数が揃っておらず推測できない）
- 出勤所属コード（複数所属のスタッフがいる場合、列の追加が要る）

未検証のまま出すと「CSVは落ちてくるがKOTに取り込めない」という中途半端な機能が
利用者に見えてしまうため、取り込みが1件通るまで `master` には入れない。
