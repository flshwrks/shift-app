# 利用実績の集計スクリプト（npm run stats）

## 対象

- `scripts/stats.ts`（新規）
- `package.json`（`stats` スクリプトを追加）

## 変更内容

本番の利用実績を数えて画面に出すだけの読み取り専用スクリプト。

- 稼働期間（最古〜最新のシフト日と月数）
- **店舗別の人数・シフト件数・最終入力日**（テスト用の店舗が混ざるため、実店舗の数字はここで見る）
- 店舗数・利用者数（ロール別）
- シフト／交代の募集／アンケート／要望の件数
- 直近6か月のシフト件数の推移（棒グラフ表示）
- 操作の記録・エラーの記録の件数

**個人データを一切出力しない。**氏名・時給・勤務時間は数えるだけで表示しない。
出力をそのまま資料に貼れるようにするための制約で、同じ理由でファイルにも書かない。
データの持ち出しが必要なときは `npm run backup` を使う。

テーブルが存在しない環境では該当行を `—` として続行する（`npm run backup` と同じ方針）。

## 理由

会社への引き渡しを進めるにあたり、**「どれだけ使われているか」を口頭で言える状態が無かった**。
価格の根拠も、全社展開の是非も、この数字の上に乗る。
毎回SQLを書くのではなく、いつでも同じ形で出せるようにした。

運用の可視化としても使う（`docs/OPERATIONS.md` §10 の定期作業に組み込む余地がある）。

## 初回の結果（2026-08-31）

- 稼働 2026-06-01〜（3か月）／2店舗・17人（スタッフ14・店舗管理者2・本部管理者1）
- **うち実店舗は10人・559件。残りはテスト用の店舗**（全体の数字をそのまま外に出すと盛ることになる。
  店舗別の内訳を出すようにしたのはこれに気づいたため）
- シフト633件（確定605件）／月別 6月100 → 7月130 → 8月228 と増加
- 交代の募集は1件のみ（ほぼ使われていない）
- エラーの未対応0件
