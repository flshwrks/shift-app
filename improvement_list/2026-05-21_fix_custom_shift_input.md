# 2026-05-21 管理者カスタムシフト入力の修正

## 対象
- `app/admin/schedule/page.tsx` — `ShiftModal` コンポーネント内の時刻入力

## 変更内容

### 1. `step="1800"` 属性の削除
- 両 `<input type="time">` から `step="1800"` を削除
- **理由**: iOS Safari など一部のブラウザで `step` 指定があると onChange が空文字列を返す既知バグがあり、時刻が更新されない端末依存の不具合が発生していた

### 2. 時刻手動変更時の shiftType 自動切り替え
- start/end の `onChange` ハンドラに `setShiftType('custom')` を追加
- **理由**: プリセット選択後に時刻を直接変更すると、保存データの `shift_type` がプリセット値（'A' 等）のままになる論理バグを修正。実際の入力時刻と一致した 'custom' として保存されるようになる
- 空文字列の場合は更新しないガードも追加（ブラウザ検証失敗時の防御）
