# シフト表にコメント本文を表示する

## 対象

- `components/TableView.tsx`
- `components/TimelineView.tsx`
- `lib/help/content.ts`（`schedule` セクション）→ `docs/GUIDE.md` は `npm run gen:guide` で再生成

## 変更内容

シフト確認（`/s/[slug]/staff/schedule`）で、シフトのコメントを時間帯の下に本文として表示するようにした。

- **表形式**: シフトのバッジ内にあった白丸を廃止し、バッジの直下にコメント本文を出す。
  `line-clamp-2` で2行を超える分は省略、`max-w-[96px]` で長文が列幅を押し広げないようにしている。
  クリックすると従来どおり `ShiftDetailModal` が開き全文が読める（`title` 属性でホバー時も全文）。
- **タイムライン**: 時刻の下にコメント本文を出す。ブロックが小さいと文字が入らないため、
  `showComment = 幅 >= 56px && 高さ >= 46px` のときだけ本文を出し、それ以外は従来の白丸で存在だけ示す。
  凡例の「コメントあり」表示はこのケースのために残している。

## 理由

コメントは白丸が付くだけで、内容を読むにはシフトを1件ずつタップする必要があった。
「今日は誰に何の指示が出ているか」を一覧で把握できず、コメントの見落としが起きる。
一覧では要点が読めて、全文はタップで確認、という2段構えにした。

## 補足

- 共有コンポーネントのため、公開シフト表（`/public/schedule`）と管理者のシフト作成画面にも同じ表示が入る。
  公開シフト表はもともとタップで `ShiftDetailModal` からコメント全文が読める状態だったので、公開範囲は変わらない。
- 表形式の画像保存（`useTableExport`）にもコメントが写る。`line-clamp` は既存の
  メモ欄（`MemoCell`）で `html-to-image` 経由の出力実績がある。
- 検証は一時ページ（モックデータで両ビューを描画）を作って `npm run dev` で目視確認し、確認後に削除した。
- バージョンは 2.9.2（パッチ）。KING OF TIME 連携（2.10.0 予定）は保留中で未コミットのため、
  先にこの変更だけを 2.9.1 の次として切っている。
