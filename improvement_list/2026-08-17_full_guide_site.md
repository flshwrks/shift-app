# 使い方の完全版サイトを作り、アプリから飛べるようにした（Ver.2.9.0）

## 背景

アプリ内ヘルプ（`HelpModal` / `docs/GUIDE.md`）は「操作中に開く早見表」として作ってあり、
1画面あたり手順4〜6行という粒度に収めている。そのため、
シフト種別の一覧・実働時間の休憩控除・提出期間のロジック・役割ごとの権限差といった
「一度ちゃんと読めば以後迷わない」種類の情報を載せる場所が無かった。

運用者から「使い方の完全版をURLで持ち、アプリから飛べるようにしたい」という要望。

## 対象

- **新規サイト（Artifact）**: シフト管理アプリ 使い方
  https://claude.ai/code/artifact/d20ce750-d2b4-4ceb-9392-ca5cf904bf1d
- `lib/routes.ts` — `FULL_GUIDE_URL` を追加
- `components/AppMenu.tsx` — メニューに「使い方（詳しい版）」を追加（別タブで開く）
- `components/icons.tsx` — `IconExternalLink` を追加
- `lib/help/content.ts` — 各役割のヘルプから完全版への言及を追加（`docs/GUIDE.md` も再生成）

## 構成の判断

### 役割で章を分けた

スタッフ／店舗管理者／本部管理者の3章立てにし、共通部分（ログイン・画面の骨格・
シフト種別・実働時間・提出期間）を先頭にまとめた。
役割ごとに別ページに分けるのではなく1ページに収めたのは、
店舗管理者はスタッフの操作も全部できるため、章をまたいで読む必要があるから。
追従する役割ナビで移動できるようにしてある。

### 在庫管理アプリは別サイトのまま

既存の「在庫管理アプリ 使い方ガイド」はそのまま残し、
シフト側の末尾からカードでリンクするだけにした。
1つのサイトに統合すると、どちらのアプリの話をしているのか読み手が見失う。

### プロモーション要素を持たせない

「何ができるか」を売る文章は書かず、「どう操作するか」だけに絞った。
読み手は既に使うことが決まっている人なので、説得は不要。

### デザイン

在庫管理ガイドと同じトークン（コバルト + slate系ニュートラル、
Hiragino Sans → Yu Gothic UI の書体スタック）を使った。
2つのガイドを行き来したときに別サービスに見えないようにするため。
シフト種別の色は `lib/types.ts` の `SHIFT_COLORS` と同値にし、
アプリ画面で覚えた色がそのまま通用するようにしている。

役割の識別にはコバルト／深緑／菫の細い左レールだけを使い、
章ごとに配色を変えるようなことはしていない（読みづらくなるため）。

## 画面の図について

実際のスクリーンショットは入れていない。ログインが必要な画面が大半で、
こちらから撮影できないため。代わりにヘッダーとボトムナビを
HTML/CSSで再現した図を置いてある（バッジの意味など、説明が必要な箇所のみ）。

実機のスクリーンショットに差し替えたい場合は、画像を渡してもらえば埋め込める。
