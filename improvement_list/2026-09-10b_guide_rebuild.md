- `app/guide/parts.tsx` / `content.tsx` / `GuideNav.tsx`（新規）
- `app/guide/GuideContent.tsx`（削除）

## 実装のバグ修正

**店舗IDの編集で、ランダム接尾辞が付いていなかった。**
POST は `withRandomSuffix()` を通すのに PATCH は入力値をそのまま保存しており、
編集で `umeda` のような推測可能なIDに戻せてしまう状態だった（F-6 の対策に穴）。
UI 側は「末尾にランダムな6文字が自動で付きます」と表示しており、実装と食い違っていた。

`hasRandomSuffix()` を作っておきながら使っていなかったのが原因。
すでに接尾辞が付いている値はそのまま通し、付いていない場合だけ付与するようにした
（無条件に付けると `umeda-k3f9q2-x8m2p1` と伸び続けるため）。

**休憩控除の判定基準の表記が誤っていた。**
`netWorkMinutes()` は「シフトの長さ（終了−開始）」で分岐しているが、
ガイドと `docs/GUIDE.md` の表は「実働が8時間を超える」と書いていた。
8:00〜14:30（長さ6.5h）は45分引かれるのに、表を読むと「控除なし」に見える。
**コードが正しく表記が誤り**だったため、表記側を直した。

## ガイドの作り直し

### 構成（マスタールール）

役割タブを廃し、`/guide/[role]` の静的3ページ＋ハブにした。
どの役割も同じ5層で並べ、層の名前がそのまま「どこに何が書いてあるか」の答えになる。

```
さいしょに1回だけ … 2回目からは読まなくてよい（開く／ログイン／画面の名前／用語）
毎月やること       … 毎月かならず通る操作。すべて番号つき手順
ときどきやること   … 起きたときだけ
困ったとき         … 症状から引く。手順は書かず次の連絡先で締める
早見表             … 読むのではなく見る
```

### 役割間の参照をなくした

「スタッフができることは全部できます」型の書き方を全廃。各ページに必要なことを全部書き、
重複はコンポーネント側で吸収した。店舗管理者ページにはログイン手順が1行も無かったが、
これも解消。本部管理者ページには共通事項（開く・シフト種別・実働時間）が入っていなかったので追加した。

### 事実誤りの修正

- 本部のナビは2つではなく3つ（店舗一覧／要望／エラー）
- メニューに「詳しい使い方」が抜けていた（3箇所）
- 「自分の**列**が強調」→ 実際は**行**
- 「右端に月計」→ スタッフには月計列が出ない。月合計はヘッダーの「今月◯h」
- 図5「いちばん上の行が実働時間」→ 実際は3行目（日付→メモ→実働時間）
- 「管理者は要望を送れません」→ 本部管理者も送れない
- 依頼の自動削除は「管理者が依頼管理を開いたとき」

### 書かれていなかった操作の追加

公開シフト表（定義ごと無かった）／`+ シフト追加` も未確定で入ること／シフト種別は
`保存する` を押すまで反映されないこと／日をまたぐ勤務は登録できないこと／申請バッジは3種類／
提出忘れを防ぐ3つのお知らせ／エラー画面／ナビの赤い丸／調整依頼の取り消し（状態で分岐）／
スタッフの削除（シフトも消える・元に戻せない）／権限変更は最長45分／同じブラウザで2アカウント不可／
タイムラインの色／未提出者の定義／操作の記録に残る操作／人件費の初期時給は特定地域の最低賃金／
店舗削除は取り消せない

### 書き手の主観を排除

「〜のためです」「〜という仕組みです」で終わる説明を全削除。結果だけを書いた。

### UI

- 見た目のルールを2つに固定し、冒頭で凡例を出す（**青＋下線＝このページで押せる／灰色の枠＝アプリの中の名前**）
- 注意書きを色ではなく形で3段階に（補足＝枠なし／注意＝行頭の罫＋ラベル／**重要＝地色つき、1ページ2〜3件だけ**）。
  以前は同じ見た目のボックスが31個あり、最重要の「まとめて提出」が埋もれていた
- 追従バーに「4/14 節名」と目次ボタン。全節にアンカーがあったのに目次が無くデッドコードだった
- 画面写真のキャプションを**画像の前**に移動（縦に長いため、後ろだと何を見るか分からないまま眺めることになる）。
  図番号を付け、`unoptimized` を外して実寸を渡した
- 権限表はスマホでは表をやめてリストにした（375pxで必ず横スクロールしていた）。自分の役割の列を強調
- コントラスト不足の色を全廃（`text-slate-300` 1.56:1、`divide-slate-50` 1.06:1 など）
- タップ領域を44px以上に

### 印刷

`@media print` を `.guide-doc` / `.guide-no-print` にスコープを切って追加。
**`details > div { display: block }` で「よくある質問」の答えを必ず出す**（従来は閉じたまま印刷され、
質問だけで答えの無い紙になっていた）。

### 役割の受け渡し

アプリのメニューは、ログイン中の役割に応じて `/guide/{staff|admin|hq}` へ直接遷移する。
役割を知っているのに読者に選ばせ直していたのをやめた。
