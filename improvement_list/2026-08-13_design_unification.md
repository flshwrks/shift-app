## 変更内容

### 1. クラスではなくスケールの定義を差し替えた

この画面群には `slate-*` / `blue-*` を使ったクラス文字列が **1000箇所以上**、
`rounded-lg` / `xl` / `2xl` が **222箇所** ある。

1つずつ `ink-*` / `ai-*` に書き換えると、

- 差分が巨大になり、レビューで実質的に読めない
- 書き換え漏れが「まだらな色」として画面に残る
- 392件の実データが乗っている本番アプリでの事故確率が上がる

ので、`@theme` で **スケールそのものの定義を新パレットへ差し替えた**。
既存のクラスは1文字も触っていない。

```css
--color-slate-500: #67717D;  /* = ink-3  4.61:1 */
--color-blue-600:  #0A66C2;  /* = ai-600 */
--radius-lg: 4px;            /* Tailwind既定の8pxではない */
```

`rounded-full` は別変数なので影響しない（アバターの丸は丸のまま）。

**新しく書くコードでは意味付きトークン（ink / rule / ai / alert / ok）を使うこと。**
`slate-*` / `blue-*` は移行済みの既存コードのための別名にすぎない。

### 2. 状態色のアクセシビリティ修正

Tailwind 既定値のうち3つが、小さい文字で WCAG AA（4.5:1）を満たしていなかった。

| 用途 | 旧 | 比 | 新 | 比 |
|---|---|---|---|---|
| エラー文 `text-red-500` | `#EF4444` | 3.76:1 | `#C62B1F` | 5.19:1 |
| 承認済み `text-emerald-600` | `#059669` | 3.40:1 | `#0A7A4B` | 5.01:1 |
| 承認済み `text-green-600` | `#16A34A` | 3.03:1 | `#0A7A4B` | 5.01:1 |

`green` と `emerald` が同じ「正常・承認済み」の意味で混在していたので同値にした。

`amber` / `orange` / `violet` は既定で AA を満たしており、かつ役割の色分け
（管理者・公募・指名）として意味が付いているため触っていない。

### 3. 影を落とした

`shadow-[0_1px_2px_rgba(16,24,40,0.04)]` 等を24箇所すべて削除。
区切りは罫線が担うので影は要らない（DESIGN_SYSTEM §2.1「浮かせない」）。

## 理由

- 2つのアプリは**同じスタッフが同じ日に行き来する**。配色や書体が違うと、
  同じ会社の別システムではなく「別のサービス」に見える
- 色の差し替えを「クラスの一括置換」ではなく「定義の差し替え」で行ったのは、
  **本番稼働中のアプリで書き換え漏れを出さない**ため。定義なら1箇所を見れば正しさが確認できる
- `red` / `emerald` / `green` の修正は見た目の統一ではなく**実害の修正**。
  エラー文と「承認済み」は、業務上いちばん読み違えてはいけない2つ
